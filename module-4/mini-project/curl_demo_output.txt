Bookstore Integration API - cURL test run

### 1. Request without an API key (expect 401)
$ curl /api/books
HTTP 401
{
    "error": {
        "code": "unauthorized",
        "message": "A valid X-API-Key header is required"
    }
}

### 2. Get book details from Inventory (expect 200)
$ curl -H X-API-Key: dev-key-123 /api/books/B001
HTTP 200
{
    "author": "Chinua Achebe",
    "book_id": "B001",
    "isbn": "9780385474542",
    "price": 950,
    "stock": 12,
    "title": "Things Fall Apart"
}

$ curl -X PUT -H X-API-Key: dev-key-123 -H Content-Type: application/json -d {"status":"dispatched","courier":"G4S Courier","tracking_number":"G4S-778812"} /api/deliveries/DEL-0001

### 6. Order an out-of-stock book (expect 409)
$ curl -X POST -H X-API-Key: dev-key-123 -H Content-Type: application/json -d {"customer":{"name":"Brian Otieno","email":"brian@example.com"},"items":[{"book_id":"B003","quantity":1}],"payment":{"method":"card","token":"tok_test_456"},"delivery_address":"4 Oginga Odinga St, Kisumu"} /api/orders
HTTP 409
{
    "error": {
        "code": "insufficient_stock",
        "message": "Only 0 of B003 in stock, 1 requested"
    }
}

### 7. Declined payment (expect 402)
$ curl -X POST -H X-API-Key: dev-key-123 -H Content-Type: application/json -d {"customer":{"name":"Brian Otieno","email":"brian@example.com"},"items":[{"book_id":"B002","quantity":1}],"payment":{"method":"card","token":"tok_declined"},"delivery_address":"4 Oginga Odinga St, Kisumu"} /api/orders
HTTP 402
{
    "error": {
        "code": "payment_declined",
        "message": "The payment was declined by the provider"
    }
}
